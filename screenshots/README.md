# Application Visual Assets & Screenshots

This directory contains light-theme visual assets, architecture diagrams, analytics charts, and application previews for the **Student Performance Intelligence and Academic Analytics** system.

## Generated Assets Overview

| Filename | Description | Dimensions | Usage |
|---|---|:---:|---|
| [`banner_light.png`](banner_light.png) | Modern light-theme hero header banner with key stats | 1200 x 420 | `README.md` header |
| [`pipeline_architecture.png`](pipeline_architecture.png) | 7-stage architecture and data processing flow diagram | 1200 x 620 | `README.md` architecture section |
| [`analytics_charts.png`](analytics_charts.png) | 4-panel statistical distribution charts (Matplotlib) | 3600 x 2700 (300 DPI) | `README.md` analytics section |
| [`terminal_dashboard_preview.png`](terminal_dashboard_preview.png) | Light terminal execution window mockup | 1200 x 780 | `README.md` dashboard section |
| [`linkedin_showcase.png`](linkedin_showcase.png) | 16:9 LinkedIn project card preview (also in root as `image.png`) | 1200 x 675 | LinkedIn post attachment |

## Regenerating Visual Assets
All assets can be regenerated at any time using:
```powershell
python generate_assets.py
```
