# Application Screenshots Directory

This directory is intended to store genuine screenshots of the **Student Performance Intelligence and Academic Analytics** system in action.

## Instructions for Adding Application Screenshots
1. Run the terminal application:
   ```powershell
   python main.py
   ```
2. Capture screenshots of the running dashboard sections (e.g., Overview, Performance Table, Subject Performance, Ranking, and Findings).
3. Save the image files inside this directory using standard names:
   - `terminal_overview.png`
   - `individual_performance.png`
   - `subject_performance.png`
   - `student_rankings.png`
4. Run the unit test suite and capture the test execution:
   ```powershell
   python -m unittest discover -s tests -v
   ```
5. Save the test execution capture as `unit_tests_passed.png`.
6. Reference these images in `Project_Documentation.md` under Section 7 (Output / Screenshots).
